**Steadier answers, and fewer surprises when something goes wrong.**

Tycho is a voice co-pilot for Star Citizen. You hold a button (push-to-talk), say something like "gear down" or "where's the best place to sell gold?", and Tycho presses the right keys or answers out loud. Version 0.5 is mostly about what happens around the answer: finding the thing you asked about, getting trade routes quicker, and coping when your graphics card runs short.

## What's new

### Asking about a ship or an item by the wrong kind of name
Some names belong to both a ship and an item. Asked about the "Cutlass Black", Tycho could answer with the Cutlass Black plushie. Now it checks the Star Citizen Wiki's search, sees the name is a ship, and answers about the ship. It works the other way too: ask about "the Gallant" as a ship, and Tycho finds the Gallant rifle. Weapons named after a ship, like the "Mantis gatling", stay weapons.

### Trade routes from where you are
"I'm at Obituary in Pyro, what's the best route for refined gold?" used to make two requests to UEX, the trade data site, and the first one was large. Now Tycho asks for the routes from where you are, for that commodity only, in one small request. If one shop is slow to answer, Tycho leaves it out instead of letting it hold up the whole answer.

### When your graphics card runs out of room
Tycho recognises your speech on the graphics card when it has room, and switches to the processor when Star Citizen takes the memory. That switch is now cleaner:

- **Tycho no longer acts on old speech.** If the card ran short in the middle of a request, Tycho used to load the processor copy and then carry out what you'd said, about 20 seconds later. Now you hear the "not done" sound at once, and Tycho loads the processor copy in the background. Until it's ready, requests get the same sound: say them again in a moment.
- **It tries again if the switch fails.** If the processor copy couldn't load (for example, the game held the memory for a moment), Tycho used to stay without speech recognition until you restarted it. Now it tries again 30 seconds later, then waits longer between tries, up to 5 minutes. The log says why in one line.
- **It frees the card's memory first,** so the game gets it back sooner.

### Safer with shared keys
Tycho won't press a key combination if part of it is, on its own, an action you'd have to confirm. For example, if Eject is bound to right Alt alone and Lights to right Alt + X, pressing Lights would press right Alt first. Tycho now refuses, and tells you which key clashes: "Lights is on ralt+x, which holds down ralt, and ralt is Eject." Rebind one of them in the game's keybindings.

### Smaller fixes
- **Long answers with a look-up get their time again.** Since 0.4, an answer that needed a look-up (prices, a ship) could run out of time while it was still coming in. Each look-up now gives the answer more time as soon as it starts, as it did before 0.4. "Checking." still comes only when no key press follows.
- **Room for the speech model:** before it downloads the speech model (2.5 GB, once), Tycho checks your drive has room. If not, it says how much it needs, how much is free, and on which drive.
- **Sounds no longer hold Tycho up,** the first request after you change your keybinds is as quick as any other, and quitting shuts everything down cleanly.

## If you've written your own commands

This only matters if you've edited `%APPDATA%\tycho\commands.toml` by hand. If a command there has a `requires` or `accepted_risks` value Tycho doesn't know, such as a typo, the whole file is now refused when it loads. Before, the typo was ignored silently, and that command was always refused.

After you upgrade, a file like that stops working, and Tycho uses only its built-in commands until you fix it. The **Commands** page in Tycho's window says so, and `tycho check` names the value and the ones allowed. To fix it, correct or remove the value, then run `tycho check` again. Most players won't see this: the Tycho commands skill for AI agents doesn't add `accepted_risks`.

## Install or upgrade

Download `TychoSetup-0.5.0.exe` below and run it. It installs for you only, with no administrator prompt. Upgrading keeps your settings, keys, commands and speech model.

The installer isn't code-signed yet, so Windows SmartScreen says it's from an unknown publisher: choose **More info**, then **Run anyway**. An AI agent can also do it for you: see [Set up with an AI agent](https://github.com/benshapyro/tycho-ai#set-up-with-an-ai-agent). More in the README's [Install](https://github.com/benshapyro/tycho-ai#install) section.

## Good to know
- **You need your own keys:** an Anthropic (Claude) key for questions and anything said differently, and optionally an ElevenLabs key for Tycho's voice.
- **Speech recognition on the processor works, but it's slower.** To keep it on the graphics card, start Tycho before Star Citizen.
- **The Tile needs Borderless window mode** in the game's graphics settings; exclusive fullscreen hides it.
- **Tycho presses keys only while Star Citizen is the window in front,** and asks you to say "confirm" before anything you can't undo, like ejecting.
